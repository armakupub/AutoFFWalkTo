# Auto Fast Forward Walk To

Project Zomboid mod, automatically enables fast forward while your character walks to a destination.

Published on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3700497455).

## Usage

1. Press Walk To (default: `Y` or `Z`) and click a destination, or right-click an interaction that requires walking.
2. The game speeds up automatically while your character walks.
3. Speed resets to 1x on arrival, on danger, or on `WASD` input.

Speed level is configurable in Mod Options: `Disabled`, `>>`, `>>>`, `>>>>`.

## Requirements

- Project Zomboid Build 42.15 or newer
- Singleplayer only
- 12 languages localized
